So testen Sie Ihren Code

So können Sie Ihr Programm manuell simulieren und testen:

Sie können das folgende Kommando ausführen, um Ihren Code mit simulation zu überprüfen, einem lokalen VHDL-Simulator (GHDL), welcher ihren Code kompiliert, simuliert und mit einer hinterlegten Test Bench prüft.

{% set command="simulation " + slug + foldername %} {% include "command_box_with_cp.html" %}

Nach der Simulation liegt eine Waveform-Datei (.vcd) in ihrem Arbeitsverzeichnis: {{foldername}}_waveform.vcd
Öffnen Sie diese mit einem Doppelklick auf {{foldername}}_waveform.vcd und fügen Sie die gewünschten Signale zur Betrachtung hinzu: Add signals from the Netlist View → Rechtsklick auf {{foldername}}_tb → Add All Variables in Scope (Shallow). Betrachten Sie die Waveforms und suchen Sie ggf. Fehler. Nutzen Sie die Zoom-funktion um die gesamten Waveforms darzustellen. Passen sie ggf. die Skalierung der Zeitleiste mit einem Rechtsklick auf diese an: Time Unit
